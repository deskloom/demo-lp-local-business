# こもれび整体院（デモLP）

**公開ページ: https://deskloom.github.io/demo-lp-local-business/**
**制作メモ（導線・計測・AIO・品質の数字）: https://deskloom.github.io/demo-lp-local-business/case.html**
**計測の動きを見る: https://deskloom.github.io/demo-lp-local-business/?track=1**（右下に記録されたイベントが出ます）

架空の地域ビジネス「こもれび整体院」の1ページLPです。
「店舗・医院のホームページ／LPを作ってほしい」という依頼に対して、こういう品質で作れますと見せるためのポートフォリオ用デモです。

**素のHTML/CSS/JavaScriptだけ**で作っています。ビルド工程・フレームワーク・外部CDN・外部フォント・外部画像は使っていません（イラストはすべてインラインSVG）。同梱しているのは、見出し用に文字を絞った明朝フォント1つ（`fonts/komorebi-mincho.woff2`・58KB・OFL）だけです。
**店名・人名・住所・電話番号・メールアドレス・お客様の声はすべて架空**です（電話は `000-0000-0000`、メールは `example.com`）。

## スクリーンショット

撮影条件：Chromium headless（Playwright）・DPR 1・フルページ。実寸は 375x12694 / 768x10382 / 1280x9006 px。
- 本文のゴシックは端末のフォントを使うため、撮影環境（Linux）では Noto Sans JP で表示しています（Mac / iPhone ではヒラギノ、Windows では游ゴシック）。見出しの明朝は同梱フォントなので、どの端末でも同じです。
- スマホ画面下の固定ボタンはフルページ撮影だと途中に写り込むため、撮影時だけ隠しています。スクロール表示の演出も表示済みの状態で撮っています。
- 容量を抑えるため 256色に減色しています（3枚で約1.4MB）。

## ページの構成

1. ファーストビュー（キャッチコピー・Web予約／電話の2つの導線・信頼の数字3つ・「光の窓」のビジュアル）＋営業時間・定休日・アクセス・支払い方法の帯
2. CONCERN … こんなお悩みはありませんか（3つ・体の線画でつらい場所を示す）
3. POLICY … 大切にしている3つのこと
4. FLOW … 施術の流れ（4ステップ・所要時間つき）
5. MENU … メニューと料金（初回メニューを大きく・ほかは料金表）
6. VOICE … お客様の声（3件・架空と明記）
7. PROFILE … 院長あいさつ（経歴つき）
8. FAQ … よくある質問（6問）
9. ACCESS … 地図イラスト・店舗情報・受付時間の表
10. RESERVATION … 予約フォーム（入力チェック → 確認画面 → 送信）

## デザインの方針

旧版は「どのセクションも中央寄せの見出し＋影つきの白いカード」の繰り返しと、手描き風の人物イラストが、テンプレート・手作り感の原因でした。作り直しでは次の方針にしています（詳しくは制作メモの「5. デザインの方針」）。

- **色は5つ**：生成り `#f6f3ed`・石 `#ece7dd`・墨 `#1f2622`・苔 `#2e4a3b`・土 `#8e4f33`（差し色は小見出しにだけ使う）
- **書体**：見出しは同梱の明朝（しっぽり明朝のサブセット）、本文は端末の日本語ゴシック
- **大胆にするのは1か所**：ファーストビューの「光の窓」（壁に揺れる木の葉の影。動きを減らす設定では止まる）。ほかは影を使わず、細い罫線と余白で組む
- **写真の代わりは「雰囲気」で**：人物を描き込まず、光と影・逆光のシルエット・体の線画にする
- **信頼の材料を先に**：ファーストビュー直下に営業時間などの帯、アクセス欄に受付時間の表。効果を言い切る表現は使わない（テストで確認）

## 作り込んだところ

- **問い合わせへの導線**：ヘッダー（PCは電話番号も常時表示）・ファーストビュー・料金欄・フォームに予約ボタン。スマホでは画面下に「Web予約／電話する」を固定表示し、予約フォームが画面に入ったら自動で隠す。
- **フォーム**：電話かメールのどちらか必須・希望日は今日以降・相談内容10文字以上を、各欄の下にエラー表示。確認画面のあとに入力が変わったら確認を取り消す。`config.js` の `FORM_ENDPOINT` に送信先URLを入れると `fetch` でPOSTする（空のときは送信しないデモモード）。
- **AI検索・SEO**：
  - JSON-LD 2種（`HealthAndBeautyBusiness`＋料金の `Offer`、`FAQPage`）。FAQPage の質問はページに表示しているFAQと完全に一致させ、テストで確かめている
  - `llms.txt`（店の概要・料金・営業時間・FAQをAI向けにMarkdownで要約）、`robots.txt`、`sitemap.xml`
  - canonical、OGP（`og.png` 1200x630・`summary_large_image`）、theme-color、SVGのfavicon
- **計測（GA4 / GTM）**：予約・電話ボタンのクリック（どの位置か・Webか電話か）、各セクションの閲覧（0.8秒以上留まったもの）、フォームの入力開始・入力ミスの欄・確認・送信完了を `dataLayer` に積む。GTMを入れればそのままGA4のイベントになる。入力値は送らない。`?track=1` を付けると画面右下にイベントを表示する。
- **演出**：ファーストビューの木の葉の影がゆっくり揺れる（CSSアニメーション）。スクロールで各ブロックが静かに表示される（IntersectionObserver）。`prefers-reduced-motion: reduce` のときはすべての動きを止める。JavaScriptが無効でも内容はすべて表示される。
- **アクセシビリティ**：見出しは h1 が1つで順番どおり。意味のあるイラストに `role="img"`＋`aria-label`、飾りは `aria-hidden`。キーボード操作で見えるフォーカス枠。文字色はすべてコントラスト比4.5:1以上（補足の灰色の文字でも5.6:1）、入力欄の枠線も3:1以上。

## 動かし方

ビルドは不要です。`index.html` をブラウザで直接開くだけで動きます（ESモジュールを使わず classic script のみ）。

```sh
npm install                   # html-validate を使う場合のみ
npm test                      # 計51件
npx html-validate index.html case.html  # HTML検証
```

## テストと確認の結果（2026-10-23）

- `npm test`：**51件すべて通過**（入力チェック32件＋送信と計測イベント6件＋ページ品質13件）。計測のテストでは、イベントの順番と、入力値（名前・連絡先・相談内容）が dataLayer に入らないことを確かめる。制作メモに書いたイベント一覧と実装のイベント名が一致することもテストする。
  ページ品質のテストは、表示テキストに開発者向けの文言（`FORM_ENDPOINT` など）が無いこと、「デモ」の表記が3回以下に集約されていること、JSON-LD が読めて FAQPage と表示FAQが一致すること、`robots.txt`・`sitemap.xml`・`llms.txt`・`og.png`（1200x630）があること、canonical・og:image・description があること、「施術の流れ」「お客様の声」があることを確かめる。手直し前のページでは6件中4件が失敗することを確認した。
  作り直しで追加したページ品質のテスト（6件）は、外部のフォント・画像・スクリプトを読み込んでいないこと、同梱フォントが woff2・100KB以下・ライセンス同梱で、見出し（h1・h2・明朝表示の要素）の文字がすべて収録されていること、SVGに代替テキストか `aria-hidden` があること、受付時間の表と JSON-LD の営業日が一致すること、「治る」「完治」「必ず改善」「診療」などの表現が無いこと、`prefers-reduced-motion` でアニメーションを止めフォーカス枠があることを確かめる。
- `npx html-validate index.html case.html docs/og.html`：**エラー0**。
- 実ブラウザ（Chromium headless）：320 / 375 / 414 / 768 / 1024 / 1280 / 1440px で `scrollWidth` が画面幅と一致（横スクロールなし）、コンソールエラーなし、同梱フォントの読み込み成功（`file://` で直接開いた場合も含む）。空送信 → エラー表示、正しく入力 → 確認画面 → デモモードの完了表示。予約フォームが見えるとスマホの固定ボタンが隠れる。撮った画像を目視し、はみ出し・重なりがないことを確認。

- Lighthouse 12.8（作り直したページを手元の http-server で2026-10-23に計測）：モバイル設定でパフォーマンス97・アクセシビリティ100・ベストプラクティス100・SEO100、デスクトップ設定で4項目すべて100。CLS 0.001、LCP 2.1秒（モバイル・低速回線の想定）／0.5秒（デスクトップ）、転送量の合計 約156KB。
  公開ページ（GitHub Pages）での計測は、このブランチが main に入ってから行う（**未計測**）。
- 画像：外部画像・`<img>` は0枚（イラストはすべてインラインSVG）。意味のあるSVG 3点（ファーストビュー・院長・地図）に `role="img"`＋`aria-label`、それ以外の飾りは `aria-hidden`（テストで確認）。
